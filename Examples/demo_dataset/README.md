# Corpus demo dataset

Six synthetic TEM phantoms with exact ground truth, used to try Corpus
without any private data and as the regression fixture for the test suite.

## Redistribution status

| Field | Value |
|---|---|
| License | `CC0-1.0` |
| Redistribution | **allowed** |
| Provenance | Synthetic phantom generated by scripts/build_demo_dataset.py |

Every file here is generated by this repository from a fixed seed, so
redistribution is unencumbered. These are **not** real micrographs: they
exercise the workflow and pin numerical behaviour. Scientific validation
against real TEM data is Workstream F (`docs/validation/`).

> The other files under `Examples/` are working images kept for manual
> testing. Their provenance is not established, so they are **not** part
> of this redistributable set.

## Contents

```
Examples/demo_dataset/
├── images/                          6 synthetic phantoms (512×512 PNG)
├── annotations/
│   └── demo_ground_truth_coco.json  COCO masks, classes Au_core / SiO2_outer
├── ground_truth.json                per-particle truth in px and nm
├── metadata.csv                     provenance, licence, calibration
├── expected/                        expected Corpus output (regression baseline)
└── README.md
```

calibration can be compared against each other.

## Try it

```bash
python measurement_modes.py \
  --image Examples/demo_dataset/images/demo_001_core_shell_spheres.png \
  --scale 200 --shape-preset spheres --mode both
```

In the GUI: load the image, enter the scale length from the table above,
click `Mark Scale Line` across the printed bar, then `Process Image`.

## Regenerate and verify

```bash
python scripts/build_demo_dataset.py           # rewrite the dataset
python scripts/build_demo_dataset.py --check   # fail if anything drifted
python scripts/build_demo_expected.py          # refresh expected/
python scripts/build_demo_expected.py --check   # regression check (CI)
```
